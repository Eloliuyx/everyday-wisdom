# Everyday Wisdom 1.0.0

A short daily reflection for your Obsidian Daily Notes, entirely offline.

- 366 English reflections, including February 29, with a fixed entry for each calendar date.
- One Automatic insertion switch for newly created daily notes; existing notes stay unchanged when opened.
- Choose placement after properties or at the end of the note.
- Preview and confirm Backfill for existing notes, or Deletion for unchanged generated reflections.
- Preserve personal writing, properties, and edited reflections; avoid duplicate insertions.
- Read clean callouts in Live Preview and Reading view, with identifying comments available in Source mode.
- No account, telemetry, AI calls, or background network requests.
- MIT License for both the plugin and all 366 reflections.

Requires Obsidian 1.13.1 or later. Core Daily notes is the supported baseline. The owner has tested the main workflow on macOS; iOS, Android, and the exact minimum version are not yet verified. See the README for template, import, and sync limitations.

For manual installation, extract `everyday-wisdom-1.0.0.zip` into your vault's `.obsidian/plugins/` directory and enable the plugin. For an update, keep `data.json` and replace only the plugin files. The separate `main.js`, `manifest.json`, and `styles.css` attachments are provided for Obsidian's installer. `SHA256SUMS.txt` lists the release-file checksums.

Content edition: 0.4. Existing reflections are never rewritten by an update.
